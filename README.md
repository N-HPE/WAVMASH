# WaveMash

Windows desktop DJ library — download tracks from YouTube/Spotify, organize WAV files, BPM/Key lookup, playlists, and mini mode.

## Run

```powershell
pip install -r requirements.txt
python -m desktop_app
```

Copy `.env.example` to `.env` and add Spotify / GetSongBPM API keys as needed.

See [desktop_app/README.md](desktop_app/README.md) for more details.
